# Zombie Run 2 — After the Sirens

A separate, free PlayCanvas browser game for PC, touch devices and WebXR. All new visual assets are generated by project code: no Blender, paid services, asset packs or external art tools are required.

## This version

- Procedural asphalt, staggered paving and grass textures, tiled by object size and shared between matching surfaces.
- Weathered building facades, shaded plinths, entrance canopies, shop signs and mall fire escape.
- Round vehicle tyres, wheel hubs, bumpers and painted roof panels.
- Hip and shoulder joints with visible walking strides, gentle idle motion and reaching zombie arms.
- Revised lighting and outbreak briefing screen. Static scenery remains batched; shadows remain disabled to avoid adding a headset rendering cost.
- Crowd steering, obstacle recovery and 20% slower base zombie movement carried over from the latest original game.
- Blended background soundtrack and HRTF zombie audio with head-relative direction and increasing volume nearby.

## Modes

Standard starts with **20 zombies** and the five-shot shotgun. Carnage starts with **100 zombies** and replaces the shop shotgun with a **100-round machine gun**. Both retain 400 civilians, three police and two firefighters. People flee nearby zombies; infection can increase the zombie population after the game starts.

Reach the raised mall fire-escape landing to win. Zombies cannot climb it. One blocked alley contains five spare shotgun shells and six arrows. Loaded weapons can be swapped immediately, preserving ammunition in the dropped weapon.

## Controls

| Device | Controls |
| --- | --- |
| PC | WASD move; mouse look; hold right mouse or Shift to run; E picks up; left mouse fires; Q/Escape returns to menu; V toggles VR. Hold left mouse for machine gun. |
| Phone/tablet | Left movement stick; drag screen to look; RUN, PICK UP, FIRE and MENU buttons. Touch controls stay hidden on PCs, including Windows touchscreen PCs. |
| VR | Left stick moves; left trigger runs; right grip picks up; right trigger fires; B/Y restarts; A exits. Headset audio follows head rotation. |

## Run and build

Requires Node.js and npm for the existing game build system.

```sh
npm ci
npm run dev
npm test
npm run build:blazor
```

`npm run build:blazor` produces `out/index.html` and `out/assets/` with relative asset URLs. Copy the entire output into a separate Blazor static folder such as `wwwroot/ZombieRun2/`, then browse `/ZombieRun2/`. Keep the asset folder alongside index.html. VR requires HTTPS or localhost and a compatible headset/browser.

## Verification and limits

All 14 checks pass: crowd/obstacle movement, projectile and weapon behavior, energy, audio, fire-escape collision, PC/mobile/VR input logic, mode resets, deterministic textures and joint animation. Production build passes; Vite reports the existing large engine bundle warning.

Automated browser testing verified menu entry and Q exit, but could not verify the 3D appearance: the Chrome automation preview reported shader compilation failures with empty driver diagnostics, and the app browser reported WebGL unavailable. Actual PC, phone and Quest rendering, frame rate and comfort still need device testing. No headset performance claim is made. Characters remain lightweight procedural models rather than realistic scanned characters.

The included soundtrack is the previously supplied and blended After The Sirens audio. No new audio or art was downloaded for this version.
